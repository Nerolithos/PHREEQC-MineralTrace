# 初步数据库检查（未完成适用性验证）

对象：PHREEQC 3.8.6-17100 附带的 `phreeqc.dat`。摘要见 STATUS.md；各次运行保存原始数据库副本。

已直接检查原始文件：

- 存在 Ca、F、C(+4) 主物种定义以及 Calcite、Fluorite 相定义。
- Calcite 相有 log K、焓变和温度表达式；这不等于整个水溶液模型在相同温度范围已获验证。
- 数据库中的 `Ca+2 + F- = CaF+` 及其参数被注释，不能把 CaF+ 当作当前模型的活跃配合物。没有自行解除注释或从其他数据库补入参数。
- 水溶液物种包含活度修正参数；本轮尚未逐物种审查活度模型、离子强度范围或所有温度修正数据。
- 便捷正向接口只开放 25 °C、1 atm；这是一项保守的软件范围限制，不是对所有流体组成的适用性认证。

待完成：核查 F 与碳酸盐配合物完整性、活度模型及适用范围，建立 Ca–F–C 专项基准，验证电荷与物质守恒，确认高温条件及压力数据边界。不得将 Example 2 的通过替代这些检查。
